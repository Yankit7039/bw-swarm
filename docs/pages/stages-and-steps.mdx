# Stages and steps

Stages group **steps**. Steps are either **tool calls** (MCP), **LLM agents** (with optional tools), or **conditions**.

## Stage types

| `type` | Purpose |
|--------|---------|
| **`deterministic`** | Steps are intended to be predictable (still may include LLM steps in YAML). |
| **`hybrid`** | Same structure as deterministic — **LLM + tools** mixed. |
| **`poll_loop`** | Repeated **poll** MCP steps with **`exit_if`**, optional **`escalation_ladder`**. |

All standard stages include **`steps`**: a list of step objects.

**`skip_if`** — Optional Python expression string evaluated against **session state**; if true, the stage is skipped.

## Step and stage field reference

<Tabs items={["mcp_call", "llm_agent", "condition", "poll_loop"]}>
  <div>
    ### `mcp_call` step

    | Field | Description |
    |-------|-------------|
    | **`type`** | **`mcp_call`** |
    | **`tool`** | MCP name: **`adapter__function`** (e.g. `jira__get_ticket`). |
    | **`input`** | Dict passed to the tool; values can use **templating** (`{{ var }}`). |
    | **`output_key`** | Session key to store normalized result. |
    | **`skip_if`** | Optional expression; skip if true. |
    | **`input_bindings`** | Map of argument names to expressions for state. |
    | **`event_parent_agent`** | Optional label for event grouping. |
  </div>
  <div>
    ### `llm_agent` step

    | Field | Description |
    |-------|-------------|
    | **`type`** | **`llm_agent`** |
    | **`instruction`** | Prompt template (state + payload). |
    | **`output_key`** | Session key for parsed JSON output from the model. |
    | **`tool_filter`** | Optional list of MCP tool names the sub-agent may call. |
    | **`fallback_state`** | If JSON parse fails, merge this dict into state. |
    | **`input_keys`** | Optional list of state keys to emphasize. |
    | **`skip_if`** | Optional expression. |
  </div>
  <div>
    ### `condition` step

    | Field | Description |
    |-------|-------------|
    | **`type`** | **`condition`** |
    | **`branches`** | List of **ConditionBranch** objects: **`if`** (expression), **`else`** (bool), **`set`** (dict to merge into state). |
  </div>
  <div>
    ### `poll_loop` stage

    | Field | Description |
    |-------|-------------|
    | **`interval_seconds`** | Sleep between iterations (default **10**). |
    | **`max_iterations`** | Cap (default **3**). |
    | **`exit_if`** | Expression — when true, exit loop. |
    | **`poll_steps`** | List of **`mcp_call`** steps per iteration. |
    | **`escalation_ladder`** | List of **`iteration`**, **`level`**, **`label`**, optional **`steps`** (MCP calls) for that escalation tier. |
  </div>
</Tabs>

## Events emitted (examples)

The runner and agent emit **`run_events`** such as:

- **`workflow_stage_started`**, **`workflow_stage_completed`** — `stage`, `stage_type`
- **`agent_started`**, **`agent_completed`**
- **`tool_started`**, **`tool_completed`**
- **`llm_message`**
- **`condition_evaluated`**
- **`poll_iteration_started`**, **`poll_iteration_completed`**
- **`escalation_triggered`**

See [Database schema](/database-schema) for the full event taxonomy.
