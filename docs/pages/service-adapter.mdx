# Adapter service

**Code:** `adapter/` — FastAPI app in **`adapter/app/main.py`**, MCP ASGI app from **`adapter/app/mcp_server.py`**.

**Role:** Expose **all** SWARM integrations as **MCP tools** over **HTTP** (Streamable HTTP). Template pods call **`{ADAPTER_URL}/mcp`** (default cluster DNS **`http://adapter:8080/mcp`**). On startup, **`ensure_schema_and_upsert_tools()`** creates **`adapter_tool_registry`** and upserts every registered tool (name, description, JSON **input_schema**).

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| **GET** | `/health` | `{ "status": "ok" }`. |
| **MCP** | **`MCP_MOUNT_PATH`** (default **`/mcp`**) | Full URL **`http://<host>:<port>/mcp`**. |

## Tool naming

Stable external names: **`{adapter_name}__{tool_name}`** — e.g. **`jira__get_ticket`**, **`amdocs_oms__get_order_status`**.

Workflow YAML references the same string in **`mcp_call.tool`**.

## Real vs mock

<Callout type="info" title="Integrations vary by environment">
  - **Jira:** Uses real Jira Cloud when **`jira_email`**, **`jira_api_token`**, **`jira_base`** (or equivalent env) are set via secrets.
  - **AgentMail:** Uses **`agentmail`** package when configured.
  - **Most telecom backends** are **mock** implementations for demos and tests (consistent scenario data derived from IDs — see **`adapter/app/adapters/_mock_scenarios.py`**).
</Callout>

## Adding a new adapter family

<Steps>
  <div>
    Create **`adapter/app/adapters/<family>/`** with **`adapter.py`** registering tools via **`register_tool`** from **`_mcp_register.py`**.
  </div>
  <div>
    Import **`register_<family>_tools`** in **`mcp_server.py`** **`_register_all_tools`**.
  </div>
  <div>
    Rebuild image; registry upserts on boot.
  </div>
</Steps>

## Environment variables

| Variable | Purpose |
|----------|---------|
| **`DATABASE_URL`** | If set, upsert **adapter_tool_registry**; if unset, tools still serve but DB sync is skipped. |
| **`MCP_MOUNT_PATH`** | Mount path for MCP (default **`/mcp`**). |
