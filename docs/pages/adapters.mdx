# Adapter reference

Workflow YAML references tools by **MCP name**: **`adapter_namespace__tool_name`**. Example:

```yaml
- type: mcp_call
  tool: jira__get_ticket
  input:
    issue_key: "{{ order_id }}"
  output_key: ticket
```

The **adapter** service registers every tool at startup and mirrors metadata in **`adapter_tool_registry`** (see [Adapter service](/service-adapter)).
