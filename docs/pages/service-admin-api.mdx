# Admin API

**Code:** `admin-api/` — FastAPI app in **`admin-api/app/main.py`**.

**Role:** **Read-heavy** REST API over the **same Postgres** as the runtime. Exposes **templates**, **runs**, **run_events**, and **adapter tool registry**. **Proxies** external webhook-style triggers to **`POST {RUNTIME_URL}/runs`**. Supports **updating** workflow YAML on a template (**`PATCH`**).

<Callout type="tip" title="Iterate workflow YAML without rebuilding images">
  **`PATCH /templates/{template_id}`** with `{ "workflow_yaml": "<string>" }` updates inline YAML in Postgres — template pods in **DB mode** pick it up on the next run (no image rebuild).
</Callout>

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| **GET** | `/health` | Health check. |
| **GET** | `/templates/` | List templates (pagination). |
| **GET** | `/templates/{template_id}` | One template. |
| **PATCH** | `/templates/{template_id}` | Body: `{ "workflow_yaml": "<string>" }` — update inline YAML in DB. |
| **GET** | `/runs/` | List runs (`template_id`, `status`, pagination). |
| **GET** | `/runs/{run_id}` | One run. |
| **GET** | `/runs/{run_id}/events` | Events for run. |
| **GET** | `/adapters/` | All adapters with nested tools (from **`adapter_tool_registry`**). |
| **GET** | `/adapters/{adapter_name}` | One adapter’s tools. |
| **POST** | `/webhooks/templates/{template_id}` | Forwards to runtime **`POST /runs`**; supports **`{ "orders": [ ... ] }`** batch. |
| **GET** | `/webhooks/templates/{template_id}` | Sample payloads and help text. |

## Environment variables

| Variable | Default | Purpose |
|----------|---------|---------|
| **`RUNTIME_URL`** | `http://runtime:8000` | Target for webhook proxy. |
| **`DATABASE_URL`** | — | Postgres connection string. |
